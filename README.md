Marbella Run 2 is an original open-world crime game about a sun-soaked coastal city
explored on foot, by stolen car, by motorbike and by boat, with traffic and pedestrians,
a five-star wanted level backed by cruisers and a searchlight helicopter, fourteen story
missions with side hustles, property ownership and passive income, combat, a full HUD
with minimap, weather with rain and wet-road reflections, synthesized radio stations,
a start screen and local saves. Plays offline in desktop Chrome, keyboard and mouse.
